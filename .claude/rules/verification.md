# Verification

Before you tell me a task is done:

1. Run the project's checks (tests, linter, type checker) and paste the
   result. If there is no check that would have caught a mistake here, say
   so explicitly rather than implying the work is verified.
2. Re-read your own diff. State anything you changed that I did not ask for.
3. If you could not verify something, say which part and why. An honest
   "I could not test the network path" is worth more than a confident
   summary that turns out to be wrong.

Do not declare success on the basis that the code looks correct.
